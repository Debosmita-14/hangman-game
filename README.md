# 🎯 Hangman Game

A fun and interactive Hangman game implemented using **Python** and **HTML, CSS, JavaScript**.  
This project demonstrates both **command-line gameplay** and a **modern web-based UI**.

---

## 🚀 Features

### 🐍 Python Version
- Command-line based Hangman game
- Random word selection
- Input validation
- Lives system
- Beginner-friendly logic

### 🌐 Web Version
- Interactive UI with Tailwind CSS
- On-screen keyboard
- SVG-based Hangman drawing
- Real-time feedback
- Play again option
